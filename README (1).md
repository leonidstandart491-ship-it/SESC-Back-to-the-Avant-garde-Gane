# SESC — Back to Avant-garde

> 🎮 Игра-память о старом здании СУНЦ УрФУ

## 📖 О проекте

**SESC — Back to Avant-garde** — небольшая видеоигра, приуроченная к переезду **СУНЦ УрФУ** на новое место.

Цель проекта — **увековечить память о старом здании**, его атмосфере и моментах, связанных с ним. Игра позволяет по-новому взглянуть на знакомое пространство и сохранить его в цифровом виде как воспоминание для учеников, выпускников и всех, кто был связан с СУНЦ.

Проект представляет собой виртуальное путешествие по знакомым местам, наполненное отсылками, коллекционными предметами, записками и достижениями.

## 🚀 Как запустить игру

### 1. Скачайте архив

Скачайте ZIP-архив с игрой из этого репозитория.

### 2. Переместите архив на рабочий стол

Для удобства поместите скачанный `.zip`-файл на **Рабочий стол**.

### 3. Распакуйте архив

Нажмите на ZIP-архив правой кнопкой мыши и выберите:

**«Извлечь всё...»** / **«Распаковать»**

После распаковки должна появиться папка:

```text
SESC_Back_To_the_Avant-garde
```

### 4. Запустите игру

Откройте папку:

```text
SESC_Back_To_the_Avant-garde
```

и найдите файл:

```text
SESC - Back to Avant-garde.exe
```

Дважды кликните по нему, чтобы запустить игру.

> ⚠️ **Важно:** не перемещайте `.exe` отдельно от остальных файлов игры. Запускайте его непосредственно из распакованной папки.

### 🛡️ Если Windows сообщает о вредоносном ПО

При первом запуске Windows может показать предупреждение системы безопасности или SmartScreen, особенно если `.exe` не имеет цифровой подписи или ранее не запускался на компьютере.

Если вы **скачали игру из официального репозитория этого проекта и доверяете источнику**, в окне предупреждения Windows можно нажать:

**«Подробнее» → «Всё равно запустить»**

Если игра не запускается из-за ограничений прав доступа, можно также попробовать:

**Правая кнопка мыши по `SESC - Back to Avant-garde.exe` → «Запуск от имени администратора»**

> ⚠️ **Безопасность:** не отключайте антивирус или защиту Windows целиком. Если Windows показывает конкретное предупреждение о вредоносном ПО, а не просто предупреждение о неизвестном издателе, рекомендуется сначала убедиться, что файл получен из доверенного источника.

## 🏫 О СУНЦ УрФУ

Эта игра создана как цифровая память о месте, которое стало частью истории СУНЦ УрФУ.

Переезд — это не только смена здания. Это завершение одного этапа и начало другого. **SESC — Back to Avant-garde** создана для того, чтобы сохранить атмосферу старого места, связанные с ним воспоминания и маленькие моменты, которые иначе могли бы остаться только в памяти тех, кто там учился.
